# 1.0.0

First public release (2026). Featherweight is a small, no-telemetry Windows tray app for the
Logitech G Pro X Superlight 2: battery and charging status, DPI, polling rate up to 8000 Hz,
lift-off distance, sleep timers, saving settings to the mouse's onboard profile, a live battery
tray icon, start with Windows, and light/dark themes with an accent colour. MIT licensed.
